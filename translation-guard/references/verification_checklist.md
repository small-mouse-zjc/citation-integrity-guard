# 译文自检清单（Verification Checklist）

翻译完成后逐项核对，任何不通过项进 `needs_review` 或告警清单。

## 术语（术语稳）

- [ ] 每个锁定术语的译名在译文中出现（`check_terms`）。
- [ ] 同一源术语没有出现多个不同译名（`variants` 检测）。
- [ ] 未使用的锁定术语已列出，确认是否漏译。
- [ ] 标题/摘要/正文/图注/结论中同一术语译名一致（人工抽查）。

## 段落（段落全）

- [ ] 每段原文都有对应译文（`align.coverage=1.0`）。
- [ ] 无漏段（`missing` 空）、无多余段（`extra` 空）、无错位（`out_of_order=0`）。
- [ ] 跨页续段已携带上下文，未被拆成两句。
- [ ] 重复段未被重复翻译。

## 事实关系（关系准）

- [ ] 所有数字（含小数）在译文中出现（`number_lost` 空）。
- [ ] 所有单位正确（mD 不是 m、% 未丢）。
- [ ] 所有引用标记 `[n]` 保留（`citation_lost` 空）。
- [ ] 所有化学式保留（CO2 未变"（二氧化碳）"后丢失原值，`chemical_lost` 空）。
- [ ] 公式符号保真（Σ/上下标/希腊字母，`restore` 问题数为 0）。
- [ ] 否定词：原文有否定则译文有对应否定（`negation_maybe_lost` 空或已人工确认）。
- [ ] 限定词：only/mainly/约/显著等限定未丢失（`limitation_maybe_lost` 空或已确认）。

## 可核验

- [ ] 每段译文有 `evidence_index` 记录，含原文定位与译法依据。
- [ ] 译不准/不确定的段已标 `needs_review`，未含混处理。
- [ ] 术语表版本、段号规则、未译标注规则已记录，便于他人复用。

## 硬错误 vs 疑似

- **硬错误**（必须修）：数字/引用/化学式丢失、占位符丢失且值不在译文、漏段。
- **疑似**（交人工）：否定/限定词形态变化导致的"疑似丢失"、术语候选未定译名、续段是否合并。

## 输出

核验结果写入 `result.verification`（consistent/issues/needs_review），逐段明细在 `pipeline.verify.per_paragraph`，供人工接管。
