# 术语表格式与锁定规则（Glossary Format）

对应题面"术语稳"：同一术语在标题、摘要、正文、图注、结论中始终用同一译名，术语表被真正执行。

## 1. 术语表条目格式

```json
{"source":"porosity","target":"孔隙度","scope":"global"}
```

- `source`：原文术语（保留原大小写与形态）。
- `target`：锁定译名；非空=已锁定，空=候选待确认。
- `scope`：作用域（`global` / `Abstract` / `Figures` 等），默认 global。
- `variants`（可选）：已知易混的其它译法，用于 `check_terms` 检测不一致。

## 2. 术语抽取（build_glossary）

- 英文：全大写缩略语（CNN/CO2）、首字母大写词组、连字符术语。
- 中文：2–6 字连续名词短语，去停用词。
- 全篇词频 ≥ `min_freq`（默认 2）才列为候选，减少噪声。
- 人工术语表里的词条无论频次都保留。
- 未锁定（`target` 为空）的候选进 `needs_review`，**不自动分配译名**（不臆造）。

## 3. 强制锁定（lock_terms）

把术语表编译成提示串：
```
【术语锁定表（强制）】
- porosity → 孔隙度 (scope=global)
...
【约束】
1. 每个源术语全程使用指定译名，不得同义替换。
2. 数字、单位、公式、文献编号、化学式按原样保留（占位符保护）。
3. 标题/摘要/正文/图注/结论中同一术语译名一致。
```
把此串随待译文本交给模型，使术语表"真正执行"而非仅写在说明里。

## 4. 一致性验证（check_terms）

- 对每个锁定术语，检查译文中目标译名是否出现。
- 若配置了 `variants`，检测同一源术语是否用了多个不同译名 → `inconsistent_term`。
- 列出 `unused_locked_terms`（锁定术语未在译文出现，可能漏译）。
- 不一致/漏译进 `needs_review`，不强行改译文（译名最终由人工确认）。

## 5. 可复用性

术语表是独立 JSON，可跨文献、跨学科复用：换一份 `paragraphs` + 同一份 `glossary` 即可。建议按学科维护术语库（如"油气地球化学术语表"），并在 README 记录版本与来源。

## 边界

术语抽取是候选生成，译名须人工/模型确认；同形不同义（如"相"在相图 vs 相态）需按 `scope` 或人工区分；术语表不覆盖的词汇按通用译法，不在本技能保证范围。
