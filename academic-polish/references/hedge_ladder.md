# 限定强度梯度（Hedge Ladder）

润色只能保持或**在同档内**调整措辞，不能跨档加强/削弱。

| 档位 | 英文 | 中文 | 改法 |
|---|---|---|---|
| 5 确定性事实 | is / are / was observed / demonstrates | 是 / 已观测到 / 证明 | 仅在原文已有时保留；不得把 1–3 档升到 5 |
| 4 强证据 | shows / indicates clearly / supports | 表明 / 显示 / 支持 | 可同档替换为 "indicates"；不得升为 prove |
| 3 一般推断 | suggests / indicates / appears / seems / likely | 提示 / 表明可能 / 似乎 / 看来 | 可同档调为 "suggests"；不得升为 show clearly |
| 2 弱可能 | may / might / could / possibly / perhaps / potentially | 可能 / 或许 / 也许 / 有望 | 可互换；不得降为 may not 或升为 is |
| 1 条件/推测 | would / in principle / to our knowledge / we believe / presumably | 我们认为 / 据我们所知 / 理论上 / 推测 | 必须保留；删去即改变作者立场 |

## 常见违规

- `may improve` → `improves`：跨档加强，critical。
- `suggest` → `demonstrate/prove`：跨档加强，critical + booster。
- `was not observed` → `was observed` / 删除 `not`：否定丢失，critical。
- `could be associated with` → `is caused by`：因果方向与强度都变，critical。
- `在少样本条件下可能失效` → `在少样本条件下失效`：限定条件丢失，critical。

## 安全改写

- 同档同义替换：`may` ↔ `might` / `could`；`suggest` ↔ `indicate`；`可能` ↔ `或许`。
- 拆句时把限定词留在原分句：`Although X may ..., Y ...` 拆为 `X may ... . Y ...`，不要丢 `may`。
- 被动改主动时保留否定与限定：`It was not found that ...` → `We did not find that ...`。
- 删冗余时只删重复副词/空话，不删 `only/just/except/under ... conditions` 等限定语。
