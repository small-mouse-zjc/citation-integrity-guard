# 创新边界

相对基础 Agent / 通用写作工具 / 翻译工具 / 人工润色基线的边界：

1. **限定强度守恒检查**（hedge_weakened / claim_strengthened）：通用润色工具追求"更确定"，本引擎把 weakening/strengthening 当作必须告警的一等公民。
2. **守护元素抽取 + 守恒**：数字单位、引用编号、图表指向、公式、化学式、否定词在润色前后逐项核对，避免"改顺了却改错了事实"。
3. **术语表真正执行**：`check_terms` 全篇回扫 + `glossary_basis` 逐句回链，不是把术语表写在提示里就算数。
4. **逐句可回溯成稿**：每句原文—改文—修改类型—理由—守护依据—核验结论，第三方可判断该不该改。

边界：脚本不做润色措辞生成、不调用外部服务、不覆盖全部语法错误；这些由模型在锁定约束下完成，脚本负责守护与核验。
