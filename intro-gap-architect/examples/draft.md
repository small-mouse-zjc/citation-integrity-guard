# 研究背景
岩相识别是储层评价的基础环节，但其精度受限于薄片尺度差异与标注成本 [w1]。近年来深度学习被广泛用于岩相识别，然而不同路线在数据需求与适用条件上差异显著 [w2]。
# 相关工作
## 按方法路线分组
CNN 路线在碳酸盐岩薄片取得较高精度，但依赖大量标注 [w1]。半监督路线通过少量标签降低标注成本，却在复杂岩相组合下稳定性不足 [w2]。
## 按数据与评价分组
Transformer 路线在公开数据上精度更高，但数据需求大、训练成本高 [w3]。
# 研究空白
已有工作分别受制于标注成本高 [w1]、复杂组合稳定性不足 [w2] 与数据需求大 [w3]，尚未形成在少标签条件下兼顾精度与稳定性的方案。
