# 研究空白模式：判据、证据要求与误判

"说得实"要求研究空白由已引文献推出，而非作者凭空断言。`derive-gap` 实现四类可解释模式。

## 四类空白模式

| 类型 | 触发判据（引擎） | 证据要求 | 推理表述模板 |
|------|----------------|---------|-------------|
| 共同限制 | ≥2 篇工作 `limitations` 命中同一限制关键词 | 列出全部支撑文献 id | "尽管 [a][b] 取得进展，但均受限于 X，这一共同瓶颈尚未解决" |
| 未覆盖场景 | `target_scenario` 关键词未出现在已引工作的方法/题名/适用条件中 | 给出未覆盖关键词 + 支撑文献 | "现有工作集中于 A，对目标场景 B 的覆盖仍属空白" |
| 结论冲突 | 同一路线内既有正面结论词也有负面结论词 | 列出两侧文献 id | "在 R 路线上，[x] 报告有效而 [y] 报告失败，结论存在争议，需进一步厘清" |
| 评价缺口 | ≥2 篇工作缺 `data_eval` 字段 | 列出缺失文献 | "多篇工作未报告完整评价口径，阻碍了方法的横向比较" |

## 限制关键词表（可扩展）

引擎内置：标注成本高（标注/label/annotate/人工/稀缺）、泛化能力弱（泛化/generalize/跨盆地/domain shift）、可解释性不足（可解释/interpret/黑箱）、计算成本高（算力/实时/轻量）、数据样本不足（样本/小样本/limited data）。

在 `works[].limitations` 中使用这些同义词可提升召回。新领域可在引擎 `lim_patterns` 中扩展。

## 强度标记

- `strong`：≥3 篇支撑，或多篇 + 明确的冲突两侧；
- `medium`：2 篇支撑，或仅关键词级的未覆盖推断（**须人工确认语义**）。

## 常见误判（务必过滤）

1. **关键词巧合**：未覆盖场景基于词面重叠，可能把同义表述误判为空白——Agent 须核对语义后再采用。
2. **限制非瓶颈**：某限制可能已被工作自身解决，只是 `limitations` 里顺带提及——核对原文上下文。
3. **冲突非真冲突**："有效"与"失败"可能针对不同子任务，不构成同一问题上的对立——核对适用条件。
4. **伪空白**：为凑结构硬造空白。若 `derive-gap` 返回 `gap_count=0`，宁可不写空白段，也不要编造。

## 空白→贡献桥接

提供 `contribution_links`（`gap_type` 或 `gap` 匹配 claim_id）后，`result.gap_to_contribution` 给出每条空白是否被本文贡献填补（`bridged`）。`bridged=false` 的空白要么补贡献，要么删空白——引言不能"提出问题却不回应"。
