# 贡献—证据对齐规则

"对得上"要求每条贡献表述都能在正文方法/图表/实验中找到对应证据，且不夸大适用范围。

## 判定规则（align-claims）

对每条贡献（claim）：

1. **有锚点**：`evidence_refs` 非空，且每个锚点都能在 `evidence_index` 中找到 → 进入 `aligned`。
2. **悬空（unbacked）**：`evidence_refs` 为空，或含 `evidence_index` 中不存在的锚点 → 必须修正。
3. **夸大（inflated）**：命中强断言词且证据锚点 < 2 处 → 单独标注，建议下调措辞或补证据。

锚点可以是表号（表2）、图号（图3）、章节号、实验编号，须与 `evidence_index` 的键一致。`evidence_index` 提供锚点到证据文本的映射，用于核对锚点真实存在。

## 强断言词表

中文：首个、首次、唯一、全面、彻底、完全、显著优于、完美、最佳、国际领先、填补空白。
英文：first, only, comprehensive, completely, significantly outperform, state-of-the-art, SOTA, best。

命中不等于错误，但要求更多证据支撑（≥2 锚点）。"首次"若属实，须给出明确的检索/对比依据。

## 四条修正路径

| 问题 | 修正 |
|------|------|
| 贡献无证据 | 补正文对应图表/实验锚点；找不到则删除该贡献 |
| 锚点不存在 | 核对表图编号，改正或补建锚点 |
| 夸大断言 | 下调为中性表述（"优于"改"在本文设置下表现较好"），或补第二处证据 |
| 贡献与正文方法不符 | 回到正文核对实际方法，改写贡献使其与事实一致 |

## 贡献条目的写法

好的贡献条目："提出分组比较驱动的研究空白推导方法，在 3 个沉积学案例上使相关工作结构化程度提升（见表2、图3）"——含方法、范围、证据。
坏的贡献条目："本文做出了创新性贡献"——无方法、无范围、无证据，会被判 `unbacked`。

## 与引用覆盖的关系

`coverage` 检查文献元数据齐全性与近期文献覆盖；真实性须 Agent 逐条核验（DOI/数据库/原文）。贡献里提到的对比方法若引用缺失或元数据错，属于"对不上"，须一并修正。
