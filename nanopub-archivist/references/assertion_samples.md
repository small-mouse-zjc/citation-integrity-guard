# 20 条原子断言样例（assertion_samples）

跨方向可复用的原子断言样例，可直接做 few-shot 示例或 benchmark 题集。每条给出：原文段落 → 拆分后的原子断言 → 关系 → 证据锚点 → 置信度依据。所有样例为**格式示范**，非任何评测案例的答案。

## 图像识别 / 分类（5 条）

1. 原文："在碳酸盐岩薄片中，CNN 方法达到 0.92 准确率[3]。"
   断言：`CNN 方法在碳酸盐岩薄片达到 0.92 准确率`｜关系 improves｜锚点 §4 图3｜high（数值明确、直接证据）。
2. 原文："该模型对碎屑岩样本的识别精度为 0.87。"
   断言：`该模型对碎屑岩样本识别精度 0.87`｜improves｜§5 表2｜high。
3. 原文："U-Net 在孔隙分割任务上优于传统阈值法。"
   断言：`U-Net 在孔隙分割上优于阈值法`｜improves｜§4.2｜medium（定性比较）。
4. 原文："迁移学习使小样本条件下分类误差下降到 0.08。"
   断言：`迁移学习使小样本分类误差降低到 0.08`｜reduces｜§5｜high。
5. 原文："模型在未见井区的泛化能力有限。"
   断言：`模型在未见井区泛化能力有限`｜indicates｜§6｜low（定性、作者用词保守）。
