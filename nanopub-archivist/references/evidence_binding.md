# 证据绑定判据（evidence_binding）

## 最小充分证据

一条断言的证据应当：
- **最小**：只截取直接支撑该断言的那句话/那组数值，不整段照抄；
- **充分**：证据本身足以让第三方判断断言真假，不缺关键限定；
- **可定位**：能指出原文位置（页码 / 章节 / 图号 / 表号 / 段落）；
- **可回溯**：他人按位置能回到原文逐字核对。

引擎 `bind_evidence` 的检查：
- 证据为空 → `no_evidence`（error）；
- 证据 > 300 字 → `evidence_too_long`（warning），提示可能非最小，宜截取；
- 锚点缺失或格式不符 → `no_anchor`（error）；
- 断言与证据词面零重叠 → `weak_link`（warning），须人工确认是否真支撑，间接推理标 `indirect`。

## 锚点格式（ANCHOR_RE）

可识别的原文位置写法（大小写不敏感）：

| 类型 | 示例 |
|------|------|
| 页码 | `p.12` / `page 12` / `第12页` |
| 章节 | `§4` / `§3.2` / `第四章` / `第三节` |
| 图 | `fig.3` / `Figure 5` / `图3` |
| 表 | `tab.2` / `Table 1` / `表2` |
| 段落 | `第5段` |
| 行 | `L42` |

锚点应作为独立字段填写；若证据片段本身含上述位置词，引擎也接受（`has_anchor` 为真），但推荐显式写锚点字段以便回溯。

## 直接证据 vs 间接推论

| 类型 | 定义 | 例子 |
|------|------|------|
| `direct` | 原文明确陈述该断言 | "准确率达到 0.92" 直接支撑 "CNN 达到 0.92 准确率" |
| `indirect` | 需结合上下文推理得出 | 原文只给混淆矩阵，准确率需计算；或结论由多句拼合 |

间接推论必须在 `evidence_type` 标 `indirect`，并在 uncertainty 中说明推理链；不得伪装成直接证据。

## 证据与断言冲突

若证据片段与断言方向相反（如原文"未显著提升"却写成"显著优于"），不得强行绑定：
- `bind_evidence` 词面重叠检查只能发现"无重叠"，**语义冲突须 Agent 判断**；
- 冲突时把该断言标入 `needs_review`，说明冲突点，宁可 `needs_attention` 也不臆造支持。
