# 断言原子化判据（assertion_rules）

## 一条好断言的标准

一条合格的科研原子断言 = **主体 + 受控关系 + 客体**，且：
1. **单一**：只表达一个关系，可独立判断真假；
2. **可判定**：客体尽量是可核验的数值、类别或方向，而非"有效/显著"这类空话；
3. **带限定**：保留原文的条件、范围、量化词（在……条件下、约、部分、xx%）；
4. **忠实**：不夸大、不缩小，不把作者的推测写成结论。

## 复合句拆分

遇到并列/因果/转折连接词，先拆后判：

| 连接词类型 | 信号 | 处理 |
|-----------|------|------|
| 并列 | 并且/而且/同时/以及/此外/and/moreover | 拆成多条独立断言，各自绑定证据 |
| 因果 | 因为/所以/由于/因此/because/therefore | 因与果各成一条，或保留一条因果断言并标 `causes` |
| 转折 | 但是/然而/although/however | 两个分支分别成断言，冲突时标 `contradicts` |

引擎 `check_assertion` 的 `issues[].type=compound` 用于**提示可能可拆**，是否真拆由 Agent 依语义决定（有些因果本就是一条断言）。

## 过宽断言收窄

出现"所有/完全/显著/极大/永远/all/always"等词却无条件或量化限定时，报 `overbroad`。收窄办法：
- 加范围："在碳酸盐岩薄片中"；
- 加量化："准确率 0.92"；
- 加限定："部分样本""在 200℃ 条件下"。

引擎不会因为句中出现数字就认定已限定——数字须与断言主体/客体相关（如 0.92 准确率）。

## 关系方向

主体与客体方向颠倒会改变结论含义。例：
- 正：`CNN 方法 improves 准确率`（方法提升性能）
- 误：`准确率 improves CNN 方法`

用 `references/provenance_vocab.md` 的受控词表统一关系，避免同义混用（提升/改善/提高 → 一律 `improves`）。

## 置信度依据

| 等级 | 依据 |
|------|------|
| high | 直接证据、数值明确、来源可核验、作者明确陈述 |
| medium | 直接证据但无量化的定性结论，或间接推论有旁证 |
| low | 间接推论、证据跨图表、来源不全或作者用"可能/推测" |

置信度是 Agent 的价值判断，脚本不自动判定；须在 uncertainty 中说明依据。
