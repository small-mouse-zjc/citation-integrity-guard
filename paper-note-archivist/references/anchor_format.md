# 锚点格式与粒度规范

"找得回"要求每条关键笔记能回到原文具体位置。`verify-anchors` 检查锚点格式与有效性。

## 支持的锚点格式

引擎识别以下格式（正则）：
- 页码：`p.5` / `page 12` / `第5页` / `第 12 页`
- 章节：`§3.2` / `第3节` / `第二章`
- 图表：`图3` / `表2` / `Figure 4` / `Table 1`
- 段落：`第3段`

## 两条硬规则

1. **必须有独立 anchor 字段**。正文顺带写"结果见图3"只算格式识别（`has_anchor_format=true`），不算可回链——因为正文里的"图3"可能指任何东西。笔记条目要有明确的 `anchor` 字段。
2. **锚点须在有效定位表中**。若提供 `valid_anchors`（从原文抽取的实际锚点集合），笔记锚点必须命中，否则标 `bad_anchor`，防止指错位置。

## 粒度选择

| 笔记类型 | 合适粒度 | 示例 |
|---------|---------|------|
| 核心结论 | 页码 + 图表 | `p.6, 图4` |
| 方法细节 | 章节 | `§3.2` |
| 数据描述 | 章节/表格 | `§3.1, 表1` |
| 局限 | 讨论段 | `§5.2` |

锚点粒度要与可核验性匹配——笼统的"见原文"等于没有。

## 中文数字页码

"第5页""第五章"里的中文数字引擎能识别。若原文用罗马页码或特殊编号，在 `valid_anchors` 中登记，并确保笔记锚点与之一致。
