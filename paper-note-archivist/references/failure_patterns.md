# 失败模式库（阅读10 文献总结与结构化笔记）

按四问列出常见失败与降级处置：

- **对得上**：笔记骨架套通用模板非论文章节顺序 → 用 `section_alignment.inversions+section_alignment.missing_sections` 检出，见 SKILL.md 门禁。
- **留得住**：漏记结论成立的前提条件 → 用 `card_fields.missing` 检出，见 SKILL.md 门禁。
- **找得回**：笔记无原文锚点或锚点失效 → 用 `anchor_verification.no_anchor+anchor_verification.bad_anchor` 检出，见 SKILL.md 门禁。
- **用得上**：知识点重复不可比较 → 用 `knowledge_normalization.merges` 检出，见 SKILL.md 门禁。

材料不足/格式未知/外部核验失败一律显式标注，不臆造。
