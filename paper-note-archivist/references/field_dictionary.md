# 论文卡片字段字典

统一字段让同领域多篇论文可并排比较。`build-reading-card` 对缺失字段标 `not_reported`，不臆造。

## 六个核心字段

| 字段 key | 标签 | 抽取要点 | 常见坑 |
|---------|------|---------|-------|
| question | 研究问题 | 作者要明确解决的具体问题（不是领域名） | 抄摘要第一句的空泛表述 |
| data | 数据 | 数据集名称、版本、规模、来源 | 只写"用了数据"，无规模版本 |
| method_conditions | 方法条件 | 方法名 + 关键设置/前提 | 只写方法名，漏条件 |
| findings | 主要发现 | 与问题对应的核心结论（含量化） | 罗列所有结果，不分主次 |
| limitations | 局限 | 作者自述或可归纳的限制 | 完全遗漏 |
| premises | 结论前提 | **让发现成立的适用条件/假设** | 最常被漏，也是最影响复用的字段 |

## 结论前提（premises）为何关键

一个结论"方法A在数据集D上准确率0.92"若不带前提，读者会误以为普适。前提包括：
- 数据条件：仅在碳酸盐岩薄片、仅在某分辨率以上；
- 方法条件：仅在某超参配置、仅在有标注数据；
- 假设条件：假设样本独立同分布、假设无域偏移。

写法："准确率0.92（**仅在碳酸盐岩薄片、512×512分辨率条件下成立**）"。

引擎用 `当...时/仅在/假设/under/premise/assumption` 等关键词初检，Agent 须确保前提真正对应结论。

## 抽取来源

字段须回到原文具体位置（摘要、引言末、方法、结果、讨论/局限段）。每个字段可选配 `{key}_anchor` 记录锚点。`not_reported` 的字段不得填推测值。
