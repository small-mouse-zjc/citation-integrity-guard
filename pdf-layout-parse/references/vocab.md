# 可复用词表（Vocabulary）

独立维护、供他人复用的识别模式词表。脚本内已内联等价规则以保证零外部依赖；本文件是可维护副本，更新时同步 `pdf_layout_engine.py` 常量。纯 UTF-8 文本。

## 1. 章节/结构模式（SECTION_PATTERNS）

```
第[一二三四五六七八九十百\d]+[章节篇]          → 中文章/节
^\d+(\.\d+){0,3}\s+                          → 数字编号（1 / 1.2 / 1.2.3）
abstract / 摘要                               → 摘要
keywords? / 关键词[:：]                        → 关键词
references? / 参考文献 / bibliography          → 参考文献
acknowledg / 致谢                              → 致谢
appendix / 附录                                → 附录
introduction / method / results / discussion / conclusion  → 英文章节
```
编号 `1.2.3` 的层级 = 点数 + 1（1.2.3→3 级）。

## 2. 题注模式（CAPTION_RE）

```
^(图|表|fig(?:ure)?\.?|tab(?:le)?\.?)\s*(\d+)[.:：\-–\s]
```
英文 `Figure 1.` / `Fig.1:` / `Table 2.`；中文 `图1` / `表 2-1`（取主编号）。

## 3. 公式编号模式（FORMULA_NUM_RE）

```
\(\s*(\d+)\s*\)\s*$
```
行尾 `(1)` / `(2-1)` 取主编号。

## 4. 希腊字母与符号保真

保留的 Unicode 希腊字母：
```
αβγδεζηθικλμνξοπρστυφχψω  ΓΔΘΛΞΠΣΦΨΩ
```
**保真原则**：只认原文真实希腊字母 Unicode，绝不把 ASCII 字母映射为希腊字母。`GREEK_FIX`（ASCII→希腊）仅作可选 OCR 后处理，默认关闭，避免 "is"→"ιζ" 失真。

## 5. 乱码/不可读模式（REPLACEMENT_RE）

```
[\ufffd\u25a1\u25af\?]{2,}
```
连续替换符、方块、问号 → `unreadable`，如实标注不猜字。

## 6. 页眉页脚/边注位置

```
上边缘 y1 <= 9% 页高    → 页眉候选
下边缘 y0 >= 91% 页高   → 页脚候选
左窄边 x1 <= 6% 页宽    → 左边注
右窄边 x0 >= 94% 页宽   → 右边注
跨页重复 ≥2 次且达 50% 页 → 高置信页眉/页脚
纯页码 [-—]?\d{1,4}[-—]? → 页脚
```

## 7. 分栏/断行参数

```
跨栏宽块阈值：行宽 > 55% 页宽
x0 聚类容差：18pt
双栏左簇中心 < 40%w，右簇中心 > 45%w
断行合并：x0 差 <12pt、间距 <0.6 行高、字号差 <1.5、上一行非句末标点、下一行非小写/标点
表格行：同 y 带 ±3pt、≥2 片段、片段≤45字、片段间距>12pt、列数取众数
```
