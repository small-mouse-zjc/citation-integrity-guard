# 分栏与阅读顺序判定规则（Reading Order Rules）

对应题面"排得对"：双栏、多栏、跨栏与跨页内容按原版面顺序输出，不串栏、不错行、不把相邻段落拼成一句。

## 1. 页眉页脚先行剔除

- 跨页顶部 9% / 底部 9% 区域重复出现的相同文本 → 页眉/页脚（高置信）。
- 纯页码（`[-—]?\d{1,4}[-—]?`）→ 页脚。
- 左右窄边（x1<6%w 或 x0>94%w）→ 边注，移出正文。
- 被剔除项进 `clean.dropped`，附 `reason`，可回溯。

## 2. 分栏检测（detect_columns）

- **排除跨栏宽块**：行宽 > 55% 页宽者（标题、图表、公式）不参与栏起点统计。
- **x0 聚类**：容差 18pt，把正文行左起点聚成簇。
- **双栏判据**：存在左簇（中心 <40%w 且 ≥2 行）与右簇（中心 >45%w 且 ≥2 行）→ 双栏；`gutter` 取左簇最大 x0 与右簇最小 x0 之间。
- 置信度：两侧各 ≥3 行 → 0.85；否则 0.6；单栏 0.25。
- 证据：`clusters`（各簇中心）、`cluster_counts`、`wide_blocks_excluded`。

## 3. 跨栏块识别（column = X）

行满足 `x0 < gutter_left` 且 `x1 > gutter_right`（横跨中缝）→ 跨栏块（column=X），如大标题、跨栏图、公式。跨栏块作为全局锚点。

## 4. 栏内归属

- `x0 < gutter_left` 且 `x1 <= gutter_right+2` → 左栏 L。
- `x0 >= gutter_left-2` → 右栏 R。
- 其余（横跨但未被判 X）→ 归为 X。

## 5. 阅读顺序重排（核心）

按页处理，跨栏块按 y 切分区间：

```
cursor = -inf
for 每个跨栏锚点 A（按 y 升序）:
    输出区间 [cursor, A.y) 内所有栏内块：按 (y0, 栏序) 交错，同 y 先 L 后 R
    输出跨栏块 A
    cursor = A.y
输出 [cursor, +inf) 内所有栏内块（同样按 y 交错）
```

**为什么要交错而不是先左后右**：真实双栏排版是"同一水平线先读左栏行、再读右栏行"，按 y 交错才不会把整栏文字堆到一起。错行常见坑：两栏 y 接近时若只按 x 排会把左右栏拼成一句——本规则按 y 主键、栏序次键，避免该坑。

## 6. 断行合并（clean 的 merge_lines）

同一页、x0 接近（差<12pt）、纵向紧邻（间距<0.6 行高）、上一行不以句末标点结尾、下一行不以小写/标点开头、**字号接近**（差<1.5）→ 合并（只拼接文本，不插空格、不改字）。字号差异大（标题 vs 正文）不合并，防止把小节标题拼进正文。

## 7. 顺序自检

- 页码单调不回退。
- 同页同栏 y 单调不回退。
- 违规进 `order_violations`，`verify` 汇总。

## 边界

- 三栏/不等宽栏：当前按双栏近似，不规则版式交人工确认（`needs_review`）。
- 跨页续接：页末段与下页首段若句号未闭合，可提示人工确认是否同段；不自动拼接跨页段落。
