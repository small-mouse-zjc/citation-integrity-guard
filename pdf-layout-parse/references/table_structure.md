# 表格结构重建规则（Table Structure）

对应题面"拆得清"：表格行列与单元格归属准确，处理跨行跨列、合并单元格、多层表头与跨页续表，输出 Markdown/结构化数据。

## 1. 表格行识别（is_table_row）

候选行需同时满足：
- 同一 y 带（容差 y_tol=3pt）有 ≥2 个横向分离的片段；
- 每个片段文本较短（≤45 字）——整句正文不算表格单元格；
- 相邻片段 x0 间距 >12pt（列间有空隙）。

## 2. 众数筛行（关键防误判）

双栏正文"同一 y、左右各一句"极易被误判成两列表格。用**行片段数的众数**过滤：真表格各行列数一致，混入的正文行列数不同。保留片段数等于众数（且众数≥2 行）的行。这一步能把混入的正文行剔掉。

## 3. 列边界与单元格归属

- 收集所有片段 x0，聚类（间距 >18pt 新起一列）得列起点 `col_starts`。
- 每行的片段按 x0 归入最近列；同列多片段文本用空格拼接。
- 空单元格留空字符串（合并单元格的从属位），不臆造内容。

## 4. Markdown 渲染（_grid_to_markdown）

```
| 表头1 | 表头2 |
|---|---|
| 数据1 | 数据2 |
```

- 单元格内 `|` 转义为 `\|`。
- 列数取各行的最大值，不足补空格。

## 5. 跨页续表（continuations）

相邻两页的表格若列数一致、且上一页表格位于页面底部区域，标为续表候选（`from`/`to`/`cols`）。**只给候选，不自动合并**——交人工确认，符合题面"不确定项不写成事实"。

## 6. 多层表头 / 合并单元格

- 多层表头：按行保留，不强行合并到首行；`grid` 保留每行原始 cells。
- 合并单元格：空白位不继承上一行（避免臆造），在 `needs_review` 提示人工确认归属。

## 7. 证据定位

每个表格块进 `evidence_index`，`block_type=table`，`page`+`y0` 可回原文。表格的 `source_lines` 记录参与的原始行号，可回溯到 `clean.lines`。

## 边界

- 无框线、靠空格对齐的表格依赖 x0 聚类，列间距过小（≤18pt）的列可能合并，交人工确认。
- 图片型表格（扫描件内的表格）需先 OCR 成带坐标文本；引擎不直接解析图片像素。
