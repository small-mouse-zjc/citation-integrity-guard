# GB/T 7714—2015 格式映射与扩展规则

`citation_engine.py format` 内置 GB/T 7714—2015 **顺序编码制**文后参考文献表渲染。本文档说明字段映射、文献类型标识与扩展到其他规范的方法。

## 条目通用结构

```
[序号] 作者. 题名[文献类型标识]. 出版信息. DOI.
```

## 文献类型标识（TYPE_LABEL）

| type 字段值 | 标识 | 含义 |
|-------------|------|------|
| article / journal | [J] | 期刊文章 |
| book | [M] | 专著 |
| thesis / phdthesis / mastersthesis | [D] | 学位论文 |
| conference / inproceedings | [C] | 会议论文 |
| report | [R] | 报告 |
| standard | [S] | 标准 |
| patent | [P] | 专利 |
| online / electronic / preprint | [EB/OL] | 电子文献/预印本 |
| misc 或未知 | [Z] | 其他 |

输入若用中文类型词（如"期刊""学位论文"），调用前先映射到上表英文键。

## 各类型出版信息规则

- **期刊 [J]**：`刊名, 年, 卷(期): 起止页.` 卷、期、页按需出现，缺项不输出空占位。
- **专著/学位论文 [M][D]**：`出版地: 出版者, 年.` 或 `出版者, 年.`（`publisher` / `institution` / `school` 互为备选）。
- **会议 [C]**：`会议名, 年: 出版者.`
- **电子/预印本 [EB/OL]**：`年. DOI.` 有 DOI 时保留。
- 所有类型末尾若 DOI 存在，追加 `DOI: <归一化DOI>.`

## 作者格式

- 列出前 3 位作者，超过 3 位写 `前三位, 等`。
- 去掉每位作者尾部已有的句点，由渲染层统一补一个，避免句末双点。
- 姓名风格沿用输入（如 `Wang, J.`）；脚本不猜测姓/名的重排，保持与文献库一致。

## 字段备选键

| 规范字段 | 备选键（按优先级） |
|----------|--------------------|
| 期刊名 | `journal` → `container_title` |
| 会议名 | `booktitle` → `container_title` |
| 出版者 | `publisher` → `institution` → `school` |
| 出版地 | `address` |
| DOI | `doi`（归一化去前缀） |

## 中英文混排与标点

- 中文题名/刊名原样保留，不强行翻译。
- 标点统一用半角 `, : .` 后跟空格，与 GB/T 7714 的常见排版一致；如目标期刊要求全角标点，在渲染后按期刊模板替换。

## 扩展到其他规范的方法

内置仅 GB/T 7714。扩展步骤：
1. 在 `TYPE_LABEL` 基础上新增目标规范的标识映射（如 APA 不用方括号标识，映射为空串）。
2. 调整 `_format_authors_gb`：APA 用 `姓, 名首字母.` 且列出全部作者或用 `et al.`。
3. 调整 `format_entry_gb` 的出版信息顺序：APA 为 `作者. (年). 题名. 刊名, 卷(期), 页码.`
4. 用 `--number-field` 选择编号来源；著者—出版年制不依赖顺序编号，可跳过 `renumber` 直接用条目内年份与作者。

每一步修改都要配一组最小示例验证，不得只改代码不验证。

## 已知限制

- 不处理 GB/T 7714 的全部细分情形（如多位译者、多卷集、专利国别码、古籍）；遇到时标注 `needs_review` 并说明缺哪条规则。
- DOI 只做格式归一化，不联网验证真伪；真实性核验走 `verification_checklist.md`。
