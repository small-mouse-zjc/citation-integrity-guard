# 去重判据与置信度表

本文档定义 `citation_engine.py normalize` 使用的可解释去重判据。设计取向：**宁可漏并，不可误并**——误并把两篇不同文献合成一条，会直接破坏引用正确性；漏并只是多留一条待人工确认。

## 判据优先级

按置信度从高到低依次尝试，命中即停止（取最高置信度判据）。

| 判据名 | 置信度 | 条件 | 处置 |
|--------|--------|------|------|
| `doi_exact` | 0.99 | 两条的 DOI 归一化后完全一致（去 `https://doi.org/`、去 `doi:`、去大小写、去尾部句点） | 自动合并 |
| `title_year_exact` | 0.95 | 归一化标题完全一致 **且** 发表年相同 | 自动合并 |
| `fuzzy_title_author_year` | 0.82 | 标题相似度 ≥ 0.86 **且** 第一作者相同 **且** 年份相同 | 自动合并（默认阈值） |
| `version_variant` | 0.70 | 标题相似度 ≥ 0.80 **且** 作者一致，但年份或版本不同 | 不自动合并，列入 `needs_review` |
| `no_match` | 0 | 以上均不满足 | 保留为独立条目 |

归一化阈值默认 0.82，可通过 `--threshold` 调整。低于阈值的高相似命中会记录为 `not_merged_below_threshold` 决策并进入待核清单。

## 归一化规则

- **标题**：NFKC 归一化 → 小写 → 去除组合音标 → 去 LaTeX 标记（`\emph{...}`、`{}`、`$...$`）→ 标点转空格 → 压缩空白。中英文混排均支持。
- **DOI**：去除协议与 `dx.doi.org` 前缀、去 `doi:`、转小写、去尾部句点。
- **作者**：取作者列表第一位的姓（`split(",")[0]`）再归一化。
- **年份**：提取四位公元年（19xx/20xx）；无年份返回空，相关判据不命中。
- **相似度**：`difflib.SequenceMatcher` 比率，范围 [0,1]。

## 代表条目选择

判定为同一组后，从组内选择**字段最完整者**作为代表条目，其余条目的原始索引写入 `merged_from`。完整性按字段计数：title / authors / year / journal / volume / issue / pages / doi / type / abstract。

这样做的原因：预印本与正式版合并时，正式版通常字段更全；不同数据库导出合并时，取并集式的最全记录。

## 合并证据记录格式

每条合并决策输出：
```json
{
  "kept_index": 0,
  "dropped_index": 1,
  "rule": "doi_exact",
  "confidence": 0.99,
  "evidence": "DOI 均为 10.1016/j.fuel.2020.118032"
}
```

`evidence` 必须是人类可读、可回溯到原始字段的说明，便于第三方判断该不该合并。

## 已知陷阱

- **同名作者误合并**：仅作者相同、标题不相似时不会合并（`no_match`），避免把同姓作者的不同文献并在一起。
- **预印本 vs 正式版**：题名高度相似、作者一致但年份/版本不同，标 `version_variant`（0.70）交人工确认——两者 DOI 可能不同，正文引用应指向正式版。
- **会议 vs 期刊版**：同理走 `version_variant`，合并依据由作者判断。
- **中文题名 + 英文题名**：归一化后若完全不同，不会合并；如确为同一文献的中英题名，需人工在 `needs_review` 中指定。脚本不猜测跨语言等价。
- **字段缺失导致判据失效**：缺 DOI 时 `doi_exact` 不生效；缺年份时依赖年份的判据不生效，此时置信度下降并记入 `issues`。
