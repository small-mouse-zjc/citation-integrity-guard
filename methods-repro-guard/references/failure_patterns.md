# 失败模式库（写作09 方法与实验章节写作）

按四问列出常见失败与降级处置：

- **写得全**：关键步骤/参数/数据集遗漏 → 用 `completeness.missing` 检出，见 SKILL.md 门禁。
- **写得准**：参数数值凭空补出无来源 → 用 `value_verification.unsupported` 检出，见 SKILL.md 门禁。
- **做得着**：版本/种子/命令不全无法复做 → 用 `reproducibility.missing` 检出，见 SKILL.md 门禁。
- **说得住**：材料缺口不显式标注 → 用 `gap_probe.needs_author_confirmation` 检出，见 SKILL.md 门禁。

材料不足/格式未知/外部核验失败一律显式标注，不臆造。
